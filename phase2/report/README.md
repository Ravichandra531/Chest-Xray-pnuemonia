# IEEE report

`phase2_ieee.tex` is an IEEEtran conference-format LaTeX source. Upload it to Overleaf or compile it with a LaTeX installation that includes IEEEtran (`pdflatex phase2_ieee.tex`, twice). Replace the team names and institution before presenting. No LaTeX engine was available during preparation, so the PDF has not been compiled or visually checked here. The older PDF in `phase2/reports/` reports a separate experiment and does not contain this reference-checkpoint ablation.
